# Ticket SLA Calculator

A simple Ticket SLA Calculator built using:

- HTML
- CSS
- Vanilla JavaScript

## Current Features

- Ticket ID input
- Created date/time input
- Closed date/time input
- SLA hours input
- Resolution time calculation
- SLA MET/BREACHED calculation
- Remaining time calculation
- Exceeded time calculation
- Input validation

## Project Structure

- `index.html` — page structure
- `style.css` — styling
- `script.js` — application logic
